# 首页设计覆盖（优先于 MASTER）

2026-09-30：用户明确拒绝通用 SaaS/AI 宣传页的视觉和文案。保留 Master 的可访问性和清晰层级原则，不套用其中的「大 Hero + 副标题 + FAQ / Contact CTA」营销结构或默认蓝色组合。

- **界面定位**：朴素的家用资料目录，不是产品介绍页。站点名、当前状态、主要操作即可。
- **颜色**：暖白底 `#f8f9f6`、深墨色 `#242925`、深绿操作色 `#245c48`、线条 `#d8ddd6`。无渐变、玻璃效果、装饰插画和浮夸阴影。
- **空站**：主标题是网站名称，紧跟一句具体用途；「当前没有说明书」只是较小的状态标题，配两个动作「导入说明书／让 AI 帮我整理」。首页保留一小块「打开与更新」，明确直接打开 HTML 不用启动服务、添加后运行 build 并刷新。详细三步流程仅在原生 `<dialog>` 中展示，非锚点跳转或页下教程。
- **有内容**：名称 + 数量 + 搜索 + 分类 + 列表。设备型号完整可见，不依赖大卡片轮播或图标。
- **交互**：目录权限须经用户点击和浏览器许可；不支持时明确给出 AI/手动替代方法。导入成功只承诺本地文件已保存，并明确提示仍需构建。键盘可见焦点，Esc 关闭对话框，移动端字段单列。
- **写作**：删除营销形容、英文眉题、口号和无意义副标题；不能删掉产品用途、操作前提和构建闭环。表单字段就近写清生成原则，AI 提示词不要求附件的原文件路径。
